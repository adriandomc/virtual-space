Son los JPG originales 1K: 1024 × 1024, excepto Cotton Jersey de 1024 × 1025. No se descargan activos externos durante el uso de la aplicación.

`manifest.json` registra URLs originales, autores, tamaños y hashes MD5/SHA-256. Las descargas se verificaron contra el tamaño y MD5 del proveedor el 2026-10-12 y se decodificaron para verificar integridad y dimensiones. La API se usó solamente durante la preparación local con User-Agent `VirtualSpace-asset-preparation/1.0`.
