# Entorno HDR

`sunset-fairway-1k.hdr`: [Sunset Fairway](https://polyhaven.com/a/sunset_fairway), fotografiado por Greg Zaal para [Poly Haven](https://polyhaven.com). Archivo Radiance HDR original de 1024 × 512, 1,478,460 bytes. Paisaje de parque al atardecer, con cielo claro y contraste medio.

Distribuido bajo [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), permite uso y redistribución comercial sin atribución obligatoria. [Licencia del proveedor](https://polyhaven.com/license). La aplicación sirve la copia local; no depende de la API ni de servidores del proveedor.

`manifest.json` registra la URL original, tamaño y hashes MD5/SHA-256. La descarga se verificó contra tamaño y MD5 del proveedor y se decodificó con el cargador HDR de Three.js el 2026-10-12. Este entorno aporta reflejos y luz ambiental; representa una fotografía fija, no una simulación del cielo de todas las horas del día.
